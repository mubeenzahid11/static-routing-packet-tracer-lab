# Static Routing Lab (Cisco Packet Tracer)

A network with 5 routers (India, Bangladesh, Pakistan, USA, Iran) connected
using serial links, with static routes configured so all LANs can communicate.

## Topology
![Topology](Screenshot__110_.png)

## What I configured
- IP addressing on all routers and end devices
- Static routes on every router
- Pakistan router as the central hub

## Verification
- ICMP pings between PCs and laptops across different LANs
- `show ip route`, `ping`, `traceroute`

## Tools
Cisco Packet Tracer

## How to open
Download `static routing task.pkt` and open it in Packet Tracer.
